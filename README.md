# Рацион для моего солнышка

Персональный планировщик питания для Леры. Запуск без сборки и установки зависимостей:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

В каталоге **120 разных рецептов с 1000.menu**. Подборка предлагает 21 блюдо без расписания; недельная цель — 21 порция выбранных блюд. В коллекции есть каши, паста, бобовые, вареники, овощные блюда, блюда из птицы, блюда с минтаем и несладкая выпечка. Супов, блюд с тыквой, омлетов и яичниц нет. Овсяноблины оставлены: с бананом и с сыром и помидорами. В отдельных рецептах яйцо входит в тесто или связывает ингредиенты; фильтр «Без яиц» скрывает блюда с яйцами в списке ингредиентов.

Вкладка «Завтраки» доступна независимо от недельной подборки. В ней ровно 30 рецептов: каши, блины и оладьи, вафли и выпечка, вареники и котлеты. Остальные 90 рецептов составляют общую коллекцию. Завтраки не появляются в её недельных подборках и фильтрах. Отметки готовности и покупки общие для всех разделов.

«Обновить рецепты» выбирает 21 блюдо из ещё не показанных в этом круге. Подбор учитывает разные семейства блюд. После всех 90 блюд общей коллекции начинается новый круг. Подборка на стыке двух кругов не повторяет блюда предыдущей недели. Перезагрузка страницы не сбрасывает историю. Обновление заменяет подборку, не меняя список покупок; отметки приготовленного сохраняются. При переходе со старого семиблюдного меню переносятся отметки для оставшихся в каталоге рецептов.

Список покупок изначально пуст. «Добавить в покупки» на карточке или в окне рецепта добавляет одну порцию. Во вкладке покупок можно менять количество порций, сверять их сумму с недельной целью и отмечать купленные продукты. Изменение количества пересчитывает список и средние дневные значения. Состояние хранится только в localStorage браузера.

`data.js` содержит ссылки на исходные рецепты 1000.menu, адаптированные порции и продукты к подаче. Для подбора новых рецептов использованы метаданные [recipe-parser](https://github.com/playful-chef/recipe-parser); полные инструкции открываются у автора рецепта. Пищевая ценность рассчитывается приблизительно по сырому весу, с учётом подачи. Соль, специи и вода в КБЖУ не входят. Фотографии иллюстративные; все 120 фотографий хранятся в `assets/` и загружаются с самого сайта, без внешних запросов. При отсутствии сети сохраняется доступ к меню, составам, отметкам и покупкам при открытой странице.

Проверки каталога и логики ротации: `node --test tests/plan.test.cjs`.
